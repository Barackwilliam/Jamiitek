  1. Fungua console.cloud.google.com → chagua au tengeneza project → APIs & Services → Library → wezesha Google Search Console API.
  2. IAM & Admin → Service Accounts → Create (jina: jamiitek-seo, bila role). Kisha Keys → Add key → JSON — faili la JSON litapakuliwa.
